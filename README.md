# Baseline — Alpha Feedback

Public feedback and bug-report home for **Baseline**, the NBA front-office
simulation, during its closed alpha. The game's source lives in a private
repository; this repo exists so alpha testers can file issues, request a
waitlist spot, and read release notes without needing access to the code.

## Report a bug

Open a [bug report](../../issues/new?template=bug_report.yml). The most
useful reports include:

- Your team, season, and in-game day
- Steps to reproduce
- Browser and OS
- **Your exported save file** — in the game: Settings → Save and support →
  Export Save, then drag the downloaded file into the issue text box
  (zip it first if GitHub rejects the extension)

## Give feedback

Open a [feedback issue](../../issues/new?template=feedback.yml) — onboarding
confusion, simulation trust, decision friction, UI readability, or just what
made you want to keep playing.

## Join the waitlist

Open a [waitlist request](../../issues/new?template=waitlist.yml). Invites go
out in small waves.

## Release notes

See [CHANGELOG.md](./CHANGELOG.md) — mirrored from the private repo on each
alpha release.
